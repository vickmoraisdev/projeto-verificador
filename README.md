# Projeto Verificador de Idade

Projeto desenvolvido durante os estudos de JavaScript no curso do Gustavo Guanabara.

O sistema verifica a idade do usuário com base no ano de nascimento informado e exibe uma mensagem personalizada junto com uma imagem correspondente à faixa etária e ao gênero selecionado.

## 🔗 Acesse o projeto

🌐 [Visualizar Projeto](https://vickmoraisdev.github.io/projeto-verificador/)

## 📚 Sobre o projeto

O objetivo deste projeto foi praticar conceitos fundamentais de JavaScript, trabalhando com manipulação do DOM, estruturas condicionais e formulários.

O sistema:

- Recebe o ano de nascimento do usuário
- Identifica a idade automaticamente
- Verifica o gênero selecionado
- Exibe uma mensagem personalizada
- Mostra uma imagem correspondente ao resultado
- Exibe [ERRO] caso o usuário digite um ano muito antigo ou que ainda não chegou

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei:

- Manipulação do DOM
- Estruturas condicionais (`if` e `else`)
- Captura de dados com formulários
- Validação de dados
- Trabalhar com datas usando `Date()`
- Trabalhar com erros usando `window.alert()`
- Alteração dinâmica de imagens e conteúdo HTML
- Organização de lógica em JavaScript
